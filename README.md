# Bernadeth Paguio Portfolio

A responsive, static portfolio site built with semantic HTML, CSS, and a small vanilla JavaScript file for the mobile navigation menu. It has no build step, package installation, or framework dependency.

## Preview

Open `index.html` in a modern browser. The page works without a server. Google Fonts are loaded from Google Fonts when online; system fallbacks are defined for offline use.

## Content notes

The three graphic cards under Experience are illustrative summaries of work areas described in the resume, not client case studies or supplied project samples. Replace them with real work media and project details when those are available. The site avoids unverified performance claims and omits phone, street address, and references.
The supplied video sample is included at media/2nd-graphics.mp4 and plays inline. This copy is optimized for web delivery; the original source file remains unchanged in the designs folder.
