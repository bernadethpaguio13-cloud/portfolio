# Bernadeth Paguio Portfolio

A responsive static portfolio built with semantic HTML, CSS, and vanilla JavaScript. It has no build step or framework dependency and can be deployed directly to Vercel.

## Preview

Open `index.html` in a modern browser. Google Fonts load from Google Fonts when online, with local system fallbacks for offline use.

## Selected work

The portfolio features three short-form video samples: a Vic Torres introduction, a handcrafted product story, and a social storytelling reel. Compressed MP4s and poster images are included in `media/` for playback on the site.

## Contact

The contact button opens an email draft to Bernadeth. The content avoids unverified performance claims and omits private contact details such as phone number and street address.
